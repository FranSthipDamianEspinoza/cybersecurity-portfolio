# Windows Fundamentals 1 – TryHackMe

## Resumen

Completé la room **Windows Fundamentals 1** de TryHackMe con el objetivo de fortalecer mis conocimientos sobre el sistema operativo Windows, su interfaz gráfica, la administración básica del sistema y conceptos fundamentales de seguridad.

Esta room proporciona una introducción práctica a componentes esenciales de Windows que son importantes tanto para administradores de sistemas como para profesionales de ciberseguridad.

## Objetivos de aprendizaje

* Comprender la estructura básica del entorno Windows.
* Familiarizarme con la interfaz gráfica de usuario (GUI).
* Identificar directorios y componentes críticos del sistema.
* Entender la gestión de usuarios y permisos.
* Conocer el funcionamiento del User Account Control (UAC).
* Explorar herramientas administrativas básicas de Windows.

## Temas estudiados

### 1. Interfaz gráfica de Windows (GUI)

Se revisaron los principales elementos de la interfaz:

* Desktop (Escritorio)
* Start Menu (Menú Inicio)
* Search Box (Caja de búsqueda)
* Task View (Vista de tareas)
* Taskbar (Barra de tareas)
* Notification Area (Área de notificaciones)

También se exploraron opciones de personalización de la barra de tareas y los elementos visibles para el usuario.

### 2. Sistema de archivos

Se estudiaron conceptos relacionados con:

* FAT32
* NTFS

Se identificaron las ventajas de NTFS, incluyendo:

* Control de permisos
* Compresión de archivos
* Cifrado
* Auditoría

### 3. Directorios importantes de Windows

Se analizaron ubicaciones fundamentales del sistema:

```text
C:\Windows
C:\Windows\System32
C:\Users
C:\Program Files
```

Especial atención recibió la carpeta **System32**, debido a que contiene archivos críticos para el funcionamiento del sistema operativo.

### 4. Cuentas de usuario y permisos

Se revisaron los diferentes tipos de cuentas:

* Administrator
* Standard User
* Guest

Además, se exploraron los grupos de usuarios y la importancia de los privilegios dentro de un entorno Windows.

### 5. User Account Control (UAC)

Se comprendió el propósito del UAC como mecanismo de seguridad diseñado para:

* Reducir cambios no autorizados.
* Solicitar elevación de privilegios cuando sea necesario.
* Disminuir el impacto de software malicioso.

### 6. Control Panel y Settings

Se identificaron herramientas administrativas utilizadas para:

* Configuración del sistema.
* Administración de dispositivos.
* Gestión de usuarios.
* Configuración de red.
* Seguridad del sistema.

### 7. Task Manager

Se exploró el Administrador de tareas para:

* Visualizar procesos activos.
* Monitorear el uso de recursos.
* Revisar aplicaciones en ejecución.
* Identificar posibles procesos sospechosos.

## Conocimientos adquiridos para ciberseguridad

Durante esta room reforcé conceptos fundamentales que serán útiles en futuras actividades relacionadas con:

* Enumeración de sistemas Windows.
* Active Directory.
* Escalada de privilegios.
* Administración de usuarios.
* Hardening de sistemas Windows.
* Análisis básico de incidentes.

## Conclusión

Windows Fundamentals 1 proporciona una base sólida para comprender el funcionamiento interno de Windows. Los conocimientos adquiridos servirán como fundamento para laboratorios más avanzados relacionados con Active Directory, administración de sistemas Windows y pruebas de seguridad en entornos corporativos.
